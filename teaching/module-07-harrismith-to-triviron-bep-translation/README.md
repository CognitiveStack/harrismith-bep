## 1. What Module 7 is

**Module 7 develops a controlled translation framework that supports the future
development of a project-specific Triviron BIM Execution Plan.**

That is a **teaching-programme architectural decision**, established by ChatGPT
governance for this programme. **It is not a Triviron governance fact**, and it
establishes nothing about Triviron.

**Module 7 output: translation framework — not the future BEP itself.**

**Future target: project-specific Triviron BIM Execution Plan.** The target's
own document architecture is **`NOT YET ESTABLISHED`** and is not designed here.

## 2. What Module 7 is not

Module 7 is **not**:

- the actual Triviron BEP;
- an organisation-wide Triviron BIM policy;
- a Triviron corporate standard;
- an already populated project BEP;
- a fictional Triviron project;
- evidence that a Triviron project appointment currently exists;
- evidence that Triviron has adopted any particular BIM platform, role
  structure, standard or workflow;
- a reusable Triviron BEP template — the framework may later prove reusable as
  a **method**, but no template is established by this module.

## 3. Objective

**To teach how a reference implementation is translated into the evidence
requirements and governed decisions needed for a future project-specific
Triviron BEP** — which questions must be asked, which evidence must exist
before an answer may be framed, which authority must take each decision, and
how every unknown is recorded rather than concealed.

## 4. Central boundary

**Harrismith supplies reference patterns, questions and governance
distinctions. It does not supply Triviron's populated answers.**

The questions and distinctions may transfer. Harrismith's populated answers do
not. A reference implementation supplies a method, not Triviron policy.
