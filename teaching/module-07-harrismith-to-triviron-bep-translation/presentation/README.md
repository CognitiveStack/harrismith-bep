## 2. What this package is

**A bounded production handoff.** Seven Markdown files from which the external
Module 7 PowerPoint can later be built:

```text
teaching/module-07-harrismith-to-triviron-bep-translation/presentation/
├── README.md                 this file — status, authority, controls
├── deck-specification.md     global controls and fourteen slide specifications
├── slide-copy.md             visible slide wording only
├── presenter-cues.md         condensed delivery cues — fragments, not a script
├── asset-manifest.md         one-to-one slide/visual/source map and import restrictions
├── production-checklist.md   the build instrument
└── review-checklist.md       the review instrument and automatic-fail register
```

**It exists so a producer can work without:**

- reopening the complete teaching baseline;
- reinterpreting the source architecture;
- changing what any slide claims;
- inventing missing information;
- converting a question into a Triviron answer;
- hiding a typed absence or an unresolved condition;
- importing visual assets;
- changing the accepted visual forms or geometry.

## 3. What this package is not

**It is not:**

- **governance** — it decides nothing and approves nothing;
- **new teaching content** — it adds no statement, source, count or claim;
- **a new visual specification** — the accepted plan controls;
- **a visual-source package** — the accepted `M07-Snn` files control;
- **a rendered asset set** — nothing here is an image, and none is required;
- **a PowerPoint** — no `.pptx` exists or is committed;
- **a PDF**;
- **Triviron governance**;
- **a Triviron BEP**;
- **an actual or scheduled Triviron workshop**;
- **implementation evidence** — it records no project performance;
- **review evidence** — no review has been performed;
- **rehearsal evidence** — no rehearsal has been performed;
- **authority to publish** — publication automation remains **`PAUSED`**.

## 4. Authority chain and precedence

```text
controlled Harrismith sources          (may establish HARRISMITH facts only)
  ↓
accepted Module 7 teaching content
  ↓
accepted Module 7 visual specification        ← T7-J, ACCEPTED
  ↓
accepted Module 7 visual-source files         ← T7-K, ACCEPTED
  ↓
T7-L presentation assembly package            ← THIS PACKAGE, pending review
  ↓
future external PowerPoint                    ← T7-M, NOT STARTED
```

**The order runs downward and never upward.**

| If | Then |
|---|---|
| This package differs from an accepted source file | **the source file wins** |
| A source file differs from the visual specification | **the visual specification wins** |
| The visual specification differs from accepted teaching content | **the teaching content wins** |
| Teaching interpretation conflicts with a controlled Harrismith source | **the controlled source governs what Harrismith establishes** |

**A later PowerPoint never becomes authoritative because it looks finished.**

**No tier of this chain can establish a Triviron fact.** Only a controlled
Triviron source (class F — **`NONE IDENTIFIED`**) or an authorised Triviron
governance decision (**none recorded in this programme**) could, and neither is
present.

**If a defect is found in an accepted upstream layer, the producer STOPS and
refers back.** It is never repaired inside this package or inside the deck.

## 10. Elements that must not be "tidied"

A producer improving the deck's appearance is the most likely route to a
governance failure. **The following are deliberate and may not be adjusted:**

- Slide 2's **empty channel** — it is content, not wasted space;
- Slide 3's **split chain** — the STOP band is not a divider to be removed;
- the **equal styling of unanswered cards** on Slides 5–11 — there are no
  answered cards, and the sameness is the point;
- **zero-valued cells** on Slides 4 and 12 — identical to the in-use cells but
  for their figure and qualifier;
- Slide 10's **fence border weight**, which differs from the card borders on
  purpose;
- Slide 12's **offset arrangement** — aligning the cards into a row destroys the
  slide;
- Slide 13's **quadrants** — a row or column of four creates a progression;
- Slide 14's **three-line header** and its **8 pt band gaps**;
- every **boundary strip**, which is a principal object and never small print.
