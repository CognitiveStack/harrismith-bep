- [ ] Exactly **fourteen slides**. No fifteenth, no appendix, agenda, thank-you
      or contact slide.

- [ ] Every title is **exact** — none shortened, retitled or improved.

## 2. Content review

- [ ] Every verbatim string in [`slide-copy.md`](slide-copy.md) §3 appears
      **exactly**, unshortened and unsplit.
- [ ] **No `TDR-` question has been converted into a statement or an answer.**
- [ ] No explanatory prose, speaker note, caption or example has been added to a
      slide.
- [ ] Compression, where used, is only compression the accepted source permits —
      chiefly evidence-kind noun phrases.
- [ ] **No boundary text has been shortened**, moved or relegated.
- [ ] Counts appear only as quoted register values: `METHOD` **3** ·

      boundary warning or teaching distinction — **and those references must

- [ ] `METHOD` appears **only** on `TDR-009`, `TDR-013` and `TDR-021`, each with

- [ ] **`TBD` appears against no Triviron matter.**

- [ ] No status meaning is carried by colour, chip, badge, dot or traffic light.
