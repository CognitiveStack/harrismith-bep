# Module 4 — Production Checklist

**Status:** Build checklist for the PowerPoint producer. **Not governance.**

Work through §1, then §2 slide by slide, then §4. **§3 is not a checklist — it
is a list of conditions that stop the build.**

---

## 1. Global checks

### 1.1 Structure

- [ ] **Fourteen slides**, numbered 1–14, none merged and none added.
- [ ] **16:9**, reference canvas **960 × 540 pt**.
- [ ] **Slide titles exactly as specified** in [`deck-specification.md`](deck-specification.md) §4 — not shortened, not retitled for balance.
- [ ] Section order **A → B → C → D → E**, with configuration last.
- [ ] **`20.0 minutes allocated — not yet measured`** appears wherever duration is stated.
- [ ] **No slide claims a measured, rehearsed, tested, confirmed or proven delivery time.**

### 1.2 Construction

- [ ] **Native PowerPoint objects only** — shapes, text boxes, tables, lines, borders, connectors.
- [ ] **No imported diagram**, in any format: SVG, PNG, JPG, PDF, EMF, WMF.
- [ ] **No screenshot** of any kind.
- [ ] **No Mermaid**, and no output of any diagram-rendering engine.
- [ ] **No Autodesk logo, product name or platform imagery.**
- [ ] **No external icon** implying a folder, an archive, approval, or software implementation.
- [ ] **No SmartArt** anywhere — every layout family inserts a sequence, a chevron or a cycle.

### 1.3 Claims

- [ ] **No claim beyond the slide source.** Where the deck and a slide source differ, the source governs.
- [ ] **No live implementation claim** on any slide.
- [ ] **Governance status and implementation status are visible** on every slide that carries a control — never moved to the notes.
- [ ] **No blocked content is completed.**
- [ ] **No unresolved field is filled.**
- [ ] **No invented code, folder, standard, schema, authority or Triviron fact** appears anywhere.
- [ ] **No compliance, maturity, scorecard or approval colour grammar.**
- [ ] **No red failure styling on a deliberate block.**

## 4. Accessibility checks

- [ ] **14 pt minimum** for status, source and connector labels — **on every slide, with no exception for space.**
- [ ] **Text contrast ≥ 4.5:1.**
- [ ] **Line and border contrast ≥ 3:1.**
- [ ] **No meaning depends on colour**, and **neither red nor green carries meaning anywhere in the deck.**
- [ ] **Connector meaning stated in text as well as line style** — `T1` says *authority established*; `T4` says *BLOCKED*; the retention route says *Not reachable*.
- [ ] **Blocked and empty content explained in the speaker notes**, because an absence cannot be perceived by a screen reader.
- [ ] **Equal objects numerically equal** — panels, cards and bands set by coordinate, not by eye.
- [ ] **Tables are real tables** with header rows — not pictures, not aligned text boxes.
- [ ] **Reading order checked** on every slide with the selection pane.
- [ ] **Projection-scale review** — view at presentation size and confirm no status label has auto-shrunk.

### The four checks to repeat after any theme or template change

1. **Slide 3's retention connector still has no arrowhead.**
2. **Slide 3's `T4` break and Slide 13's refused gap are still visible** — some themes thicken connectors enough to close a small gap.
3. **No empty position has acquired a theme fill** — Slides 6, 7, 11, 12.
4. **No status label has auto-shrunk below 14 pt.**
