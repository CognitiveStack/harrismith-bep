## 3. Authority — and it runs one way

```text
Controlled Harrismith sources
  ↓
accepted Module 5 teaching content
  ↓
accepted visual-demonstration plan
  ↓
M05-S01–M05-S14 slide-source files
  ↓
T5-G presentation assembly package
  ↓
future external PowerPoint
```

**The order runs downward and never upward.**

- **This package implements the slide sources. It does not override them.**
- **The slide sources implement the visual plan. They do not override it.**
- **The teaching content remains authoritative for slide meaning, narrative and
  timing.**
- **Controlled Harrismith sources remain authoritative over every teaching
  layer.**
- **A future PowerPoint is derivative.** It never becomes governance, and **it
  never becomes the authoritative source merely because it looks finished.**

Where this package and a slide source differ, **the slide source is correct and
this package is the thing to fix.** Where a slide source and the visual plan
differ, **the plan is correct.** Where any teaching material conflicts with a
controlled Harrismith source, **the controlled source wins.**

## 5. Native reconstruction rule

**All fourteen visuals are rebuilt using native PowerPoint objects.**

Permitted: **native shapes · text boxes · tables · borders · lines ·
connectors**.

**Prohibited, without exception:**

- **no Mermaid** — prohibited for all fourteen visuals, individually assessed;
- **no SmartArt** — its automatic layouts imply hierarchy and sequence this
  module spends fourteen slides denying;
- **no SVG · no PNG · no JPG · no PDF import**;
- **no screenshot** of any kind — platform, ACC, CDE, folder or interface;
- **no external icon · no external imagery · no stock photography · no logo**;
- **no platform image**;
- **no live-evidence capture.** No new observation is needed and **none is
  authorised**.

**External imagery: `NONE REQUIRED` for all fourteen. Live evidence:
`NONE REQUIRED` for all fourteen.**

A screenshot would make *software implementation* concrete while this module
teaches **governance and proposed planning**. Module 5's central hazard is the
audience concluding that something is operating.

## 7. Elements that must not be "tidied"

**A deliberately incomplete, separated, blocked or empty-looking element is
carrying a claim.** Fixing it introduces a false one.

| Slide | Element that looks unfinished | The false claim "fixing" it would introduce |
|---|---|---|
| **2** | The **allocated / observed** split, and the absence-of-observation warning inside the observed frame | Merging them, or moving the warning to a footnote, asserts that **five disciplines are behind or have failed to deliver**. The record does not say that |
| **4** | The **unpopulated matrix skeleton** | Filling any cell asserts the source matrix is incomplete, **and** pre-empts the grammar taught on Slides 6–7. The source has **297 populated cells** |
| **4** | The **`D4` split call-out** — `TBD` ×5 · `—` ×4 | Collapsing it to "`D4` is `TBD`" **deletes four resolved cells** and teaches a row that does not exist |
| **6** | The **≥ 40 pt gutter** between seven function codes and the two non-function values | Closing it makes `TBD` and `—` read as **an eighth and ninth function code**. They are not codes |
| **7** | The **complete nine-cell `D4` row** | Abbreviating it asserts the row is uniformly unresolved. **Four of those cells are resolved** — those roles hold **no function** there |
| **8** | The **functional boundary still visible** through the participant overlap | Hiding it asserts that combining roles **merges the functions**. It does not — a self-check is still a checking act |
| **10** | **Three unconnected event cards** | Any arrow asserts a **mandatory sequence** the sources do not state |
| **11** | **Two separate tracks**, and the **broken `TRN-E03` → `T4`** connector | Repairing the connector asserts **`T4` is traversable**. Merging the tracks asserts an **event is a transition** |
| **12** | **Five closed gates**, none opening | Opening one, or connecting them, asserts that **clearing one releases the event**. Resolving one releases **none** of the others |
| **13** | **Seven typed distinctions kept separate**, `TBD` and `—` adjacent but ruled apart | Harmonising them asserts **one controlled universal code set** and erases that **two markers record resolved answers** |
| **14** | **Five unanswered decision groups**, every answer area empty | Filling any of them **invents a Triviron fact**. Module 7 owns the translation, and it has not been performed |
