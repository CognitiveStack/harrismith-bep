# Module 1 — Slide Copy

**Status:** Working on-slide wording. **Not the speaker script.**

Everything below is intended to be **visible on the slide**. What the presenter
*says* is in [`presenter-cues.md`](presenter-cues.md).

---

## How to read this file

| Element | Meaning |
|---|---|
| **Title** | The slide title |
| **Subtitle** | Second line, where used |
| **Main statement** | The one sentence the slide argues |
| **Supporting items** | Labels or single-line bullets — **maximum five** |
| **Diagram labels** | Text inside the visual |
| **Call-out** | A boxed or emphasised line |
| **Footer** | Small, low-contrast source note |
| **Visible warning** | A required on-slide label |

**Density limits:** one principal message, one title, one short main statement,
no more than five supporting items, items generally one line, no paragraphs, no
dense extracts. Roughly **40 visible words per slide** excluding diagram labels.

two-column comparison or a closing build where the comparison *is* the content.

questions and three takeaways. If it reads as crowded when assembled, the three
takeaways become a fifteenth slide rather than being cut.
