## 3. Rendering position

**Nine diagrams would benefit from rendering; none requires it.**

| Approach | When to use |
|---|---|
| **Rebuild natively** in the presentation tool from the Mermaid source | Default. Gives full control over type size, spacing and the dashed/solid distinctions that carry meaning |
| **Render to SVG** and place | If a renderer becomes available. Filenames are proposed above |

**Four slides need no diagram rendering at all** — 1, 5, 7 and 8 are a layout
spec and native tables.

If SVG is produced later:

- render from committed source, unchanged;
- name it after its source identifier;
- update the register's **Rendered** column;
- remember that **a render never becomes the authority** — if a render and its
  source disagree, the source is correct.
