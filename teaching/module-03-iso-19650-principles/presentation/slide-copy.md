## 1. How to read this file

| Element | Meaning |
|---|---|
| **Title** | The slide title |
| **Subtitle** | Second line, where used |
| **Main statement** | The one sentence the slide argues |
| **Supporting items** | Labels or single-line bullets — **maximum five** |
| **Diagram labels** | Text inside the visual |
| **Call-out** | A boxed or emphasised line |
| **Footer** | Small, low-contrast source or evidence note |
| **Visible warning** | A required on-slide label — used on **10 of 14 slides** |

**Density limits:** one main message · maximum five supporting items · no
paragraph blocks · **no long ISO quotation** · no full source-map table · no
complete conformity checklist · no full Harrismith delivery schedule · no raw
source extract · **no dense disclaimer wall**. Roughly **50 visible words per
slide** excluding diagram labels.

**Retain necessary distinctions even where copy runs slightly longer.** Slides 8,
13 and 14 exceed the guide deliberately — each carries a boundary that cannot be
compressed without losing its meaning.

### Slide 14 — What Triviron must verify before claiming alignment
