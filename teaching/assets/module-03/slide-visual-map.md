# Module 3 — Slide-to-Visual Map

**Status:** Visual-source baseline. **Not governance.** No rendered assets exist.

Slides 1–14 mapped to their visuals, with what each must **omit** and what the
**speaker** must supply that the visual cannot.

Controlling documents:
[`../../module-03-iso-19650-principles/visual-demonstration-plan.md`](../../module-03-iso-19650-principles/visual-demonstration-plan.md)
and
[`../../module-03-iso-19650-principles/source-map.md`](../../module-03-iso-19650-principles/source-map.md).

## 1. How to read this map

| Field | Meaning |
|---|---|
| **Primary visual** | The controlling `V` concept |
| **Slide source** | The `M03` file that implements it |
| **Type** | Mermaid · table · layout specification |
| **Five-second takeaway** | What the audience should get **before** the speaker says anything |
| **Omit** | What must not reach the slide |
| **Source label** | The classification shown **on the slide** |
| **Jurisdiction label** | Required wherever guidance is used |
| **Speaker supplies** | What the visual cannot carry |
| **Warning** | The failure the visual invites |
| **Copyright** | Reproduction risk |
| **Likely overclaim failure** | How this slide most plausibly goes wrong |

**Every slide is deliverable from repository and registered source alone.** **No
external imagery is required anywhere in this module.**

are near widely reproduced ISO figures; **none is reconstructed, and no
third-party version is reused.**
