## 1. Purpose and five-second takeaway

**Purpose.** Teach the controlled vocabulary **and** its scope — it belongs to one matrix

**Five-second takeaway.** *Seven codes, two values that are not codes, and RACI refused on the record.*

**Why this form.** The gutter is load-bearing. **If `TBD` and `—` share a frame with the seven, they read as an eighth and ninth code.**

**Simplification rule.** Definitions may not be paraphrased — they are quoted controlled wording. **If space is short, reduce type size to the 14 pt floor before cutting words.**

## 8. Status and warning treatment

**Mandatory warning: The scope line — **grammar belongs to the IM Responsibility Matrix alone****

**The scope line is mandatory.** Without it, the slide licenses the codes for use
on Slides 9–12, where they do not belong.

The refusal carries its BEP reference, so it reads as governance rather than
preference.

**Status is carried by words, never by colour alone.** Minimum visible type
**14 pt**; principal labels **≥ 18 pt**; text contrast **≥ 4.5 : 1**; border and
connector contrast **≥ 3 : 1**.

## 9. Build or reveal sequence

## 10. Mandatory omissions

- No RACI mapping, in either direction
- No eighth or ninth code

## 11. Accessibility and projection requirements

**Reading order:** panel A rows → panel B rows → scope line → refusal.

**The gutter must be described in words** — visual separation is invisible to a
screen reader, so the alt text must say that panel B is a **separate** panel of
**non-function** values.

**No information is carried by colour alone.** Connector meaning is carried by
**form and label**. Warnings remain legible at projection scale.

## 12. Screen-reader or presenter-notes description

> *Panel one, seven function terms with their BEP 5.12 definitions: Perform, carries out the activity; Check, verifies against a defined requirement; Authorise, permits progression for a defined purpose; Coordinate, organises across parties or task teams; Accept, receives for an identified purpose; Consult, is asked before the act; Inform, is told after the act. Panel two, visually separate, headed 'not function codes': TBD, allocation unresolved; dash, the role holds no function in this activity. This grammar belongs to the Information Management Responsibility Matrix only. Below: RACI is not adopted, BEP 5.12, because it collapses checking from authorising and coordinating from performing.*

## 13. Producer-failure test

**Ask a reader how many function codes there are. If the answer is nine, the
separation has failed.**

**Ask which resources use this grammar. If the answer is more than one, the scope
line has failed.**

## 14. STOP conditions

**Stop and refer back to the accepted plan if this visual would:**

- Present RACI as the grammar, or map any code to R/A/C/I
- Apply the IM grammar to the container matrix or the schedule
- Imply both matrices share one coded vocabulary
- Call `—` unresolved or blank
