## 1. Purpose and five-second takeaway

**Purpose.** Teach check selection as a **governed choice**, and fix the two
objects that carry no authority — an unapproved threshold and a clash count.

**Five-second takeaway.** *Twelve pairs built. The empty cells are the point. No
number is approved.*

**Why this form.** **The incompleteness is the teaching point.** A completed
combinatorial grid would assert that coordination means testing everything
against everything, which `S1` §8.6 expressly declines. **Empty cells that are
visibly cells — bordered, sized, present — say *not built*; missing cells would
say *not applicable*.**

**Simplification rule.** Check-type descriptions may compress to their operative
phrase. **The grid may never be completed, and no unbuilt cell may be filled,
shaded to look decided, or removed.** **`PROPOSED` and `TBD` may not be
abbreviated to symbols**, and the six check types may not be folded into the
grid.

## 5. Exact visible wording

**Every string below is mandatory on the slide.**

- *"A check exists because a meaningful interface exists"*
- *"Testing everything against everything produces volume, not insight, and
  buries the findings that matter"* — **BEP §8.6**
- **`Clash detection is one coordination technique, not the whole of coordination`**
- The six check types: **Hard Clash · Clearance / Access · Alignment / Reference ·
  Spatial Interface · Information / Readiness · Design / Interface Question**

## 8. Status and warning treatment

**Mandatory warning: the two-line block — `Software default ≠ project
requirement` and `No numeric tolerance approved` — full width and at ≥ 18 pt.**

**`PROPOSED` and `TBD` appear on every marked cell.** A single legend is **not
sufficient**, because a legend can be read past.

**Permitted numbers.** Only controlled or teaching identifiers required by the
accepted slide — **`CI-01`–`CI-12`**, and any source or status reference this
specification already requires.

**Prohibited numeric values.** No numeric tolerance · clearance measurement ·
clash count · percentage · score · pass/fail threshold · progress value ·
software-default value · any other numeric project criterion.

**Status is carried by words, never by colour alone**, and never by a coloured
chip, badge or dot. Minimum visible type **14 pt**; principal labels **≥ 18 pt**;
text contrast **≥ 4.5 : 1**; border contrast **≥ 3 : 1**.

## 13. Producer-failure test

**Search the finished slide for digits outside the permitted `CI-01`–`CI-12`
identifiers and any source or status reference this specification already
requires.** **Any digit functioning as a tolerance, measurement, clash count,
percentage, score, threshold or progress value is a STOP.**

**Ask a reader whether these checks have been run.** If the answer is *yes* or
*probably*, the per-cell `PROPOSED` has failed.

**Ask what the empty cells mean.** If the answer is *not applicable* or
*missing*, the *not all pairs are built* line has failed.
