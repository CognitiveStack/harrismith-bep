# Module 1 — Slide-to-Visual Map

**Status:** Working map for the Slides 1–14 content baseline. **Not governance.**

One row per slide. The "five-second read" column is the test that matters: if the
audience cannot take that away from the visual alone while the presenter is
still speaking, the visual is doing too much.

---

## 1. Column definitions

| Column | Meaning |
|---|---|
| **Primary visual** | The slide's principal visual source |
| **Optional support** | A second element, used only if time and space allow |
| **Type** | `diagrammatic` · `tabular` · `documentary` (an extract of a controlled document) · `external` (material not in this repository) |
| **Five-second read** | What the audience should understand from the visual alone |
| **Must be omitted** | Detail that must not reach the final slide |
| **Speaker required?** | Whether the visual is self-explanatory or depends on commentary |
| **Deliverable without external image?** | Whether the slide works with only repository-derived material |

## 3. External-material position

**All fourteen slides are deliverable using only repository-derived material.**

Three evidence sources need material that does not exist here — `V1` (project or
model image), `V9` (ACC CDE view) and `V10` (Revit or federated view). Each is an
**optional enrichment**:

| | Would enrich | Is required by |
|---|---|---|
| `V1` | Slide 1 | *nothing* |
| `V9` | Slide 9 | *nothing* — and it is **counterproductive** on Slide 10 |
| `V10` | Slide 11 | *nothing* |

A presentation assembled today from `M01-S01`–`M01-S14` covers all twenty
minutes. The absence of a hero image changes the slide's *feel*, not its
deliverability.

## 4. Type distribution

| Type | Slides |
|---|---|
| `diagrammatic` | 2, 3, 4, 6, 9, 10, 11, 12, 14 |
| `tabular` | 5, 7, 8, 13 |
| `documentary` (controlled-document extract) | 7, 8 |
| `external` (optional only) | 1 |

**Nine diagrams, four tables, two document extracts, one optional external
image.** The balance is deliberate: the plan's standing rule is that a dense
document screenshot is not a visual, so extracts appear only where the
document's *structure* is itself the teaching point — Slide 7's two matrices and
Slide 8's schedule row.

## 5. Slides where the visual cannot stand alone

Nine of fourteen require speaker commentary to be safe, not merely clearer. In
five cases the commentary carries a governance statement the visual cannot:

| Slide | What the speaker must supply |
|---|---|
| 5 | That the comparison is teaching synthesis, not a Harrismith position |
| 8 | *Why* there are no dates — no appointment, no client requirements, none invented |
| 11 | That the cycle is **not evidenced as configured or verified** |
| 12 | That issue closure is **not** design approval |
| 13 | That incompleteness here is discipline, not failure |

A deck circulated without a presenter would misrepresent all five. If handout
distribution is ever proposed, these five need written notes attached.
