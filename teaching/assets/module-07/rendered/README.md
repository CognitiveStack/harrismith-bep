## 2. Why nothing is rendered

**Rendering was never required.** All fourteen accepted Module 7 visual
specifications are **natively reconstructible** from text boxes, rectangles,
native shapes, lines, connectors, tables, borders and fills. **No visual needs
an image**, so no rendering step exists to perform.

**`T7-K` is source production, not rendering.** The increment translates
accepted specifications into native construction records. Producing an image
would create an artefact that is harder to review than its source, easy to
mistake for a finished slide, and impossible to diff.

**A rendered picture also carries a governance risk this module cannot accept.**
Module 7's subject is that **no controlled Triviron source is identified**. A
rendered diagram reads as a finished, adopted arrangement far more strongly
than any caption can withdraw (`M7V-S32`, `M7V-S34`).

## 3. If rendering were ever undertaken

**It would require its own expressly authorised governance increment.** Nothing
in `T7-K`, and nothing in the accepted `T7-J` specification, authorises it.

Were it authorised, these would apply without exception:

| Rule | Requirement |
|---|---|
| **R1** | The native source remains **authoritative**. A render is a derivative output and **never** authority over its source |
| **R2** | **No text may be rasterised.** All type stays live, selectable and ≥ 14 pt visible / ≥ 18 pt for principal labels and every status, classification and boundary word |
| **R3** | **No external asset may enter** — no photograph, screenshot, logo, third-party image, downloaded icon, external SVG or network-dependent resource |
| **R4** | **No Mermaid, SmartArt or automatic graph layout**, at any stage |
| **R5** | **Geometry is not re-derived.** Every coordinate comes from the accepted specification, and the arithmetic self-check is re-run against it |
| **R6** | **Colour carries no meaning.** Every status, classification, absence and connector meaning stays in words |
| **R7** | Every applicable **`M7-Snn`** and **`M7V-Snn`** STOP condition survives the render, and each rendered visual is re-tested against its **producer-failure test** |
| **R8** | A render that cannot satisfy R1–R7 is **not produced**. The producer **stops and refers back** — type is never shrunk, condensed or letter-spaced to force a fit |
