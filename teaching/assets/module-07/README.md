## 4. Authority chain and precedence

```text
controlled Harrismith sources          (may establish HARRISMITH facts only)
  ↓
accepted Module 7 teaching content
  ↓
accepted Module 7 visual-demonstration plan   ← T7-J, ACCEPTED
  ↓
Module 7 visual-source files                  ← T7-K, THIS PACKAGE, pending
  ↓
presentation assembly package                 ← T7-L, NOT STARTED
  ↓
external PowerPoint                           ← T7-M, NOT STARTED
```

**The order runs downward and never upward.** A later package, render or
PowerPoint **never becomes authoritative over its source**.

- Where a source file and the accepted visual plan differ, **the plan wins**.
- Where the plan and the accepted teaching content differ, **the teaching
  content wins**.
- Where any teaching material conflicts with a controlled Harrismith source,
  **the controlled source wins**.

**A visual source may not reinterpret its visual specification.** If a source
file appears to need a change the specification does not authorise, the
producer **STOPS and refers back** — the specification is repaired by its own
governed increment, never inside a source file.

**No tier of this chain can establish a Triviron fact.** Only a controlled
Triviron source (class F — **`NONE IDENTIFIED`**) or an authorised Triviron
governance decision (**none recorded in this programme**) could, and neither is
present.

## 8. STOP handling

Every source file carries **both** STOP registers that apply to it: the accepted
teaching STOPs (`M7-Snn`) and the accepted visual-production STOPs
(`M7V-Snn`), copied from its controlling `M7V-nn` specification.

**A producer who cannot satisfy a STOP condition stops and refers back.** A STOP
is never worked around, softened, deferred to the deck, or satisfied by a
caption.

**The three controls that govern every file in this package:**

| Control | Rule |
|---|---|
| **Classification ≠ status** | The five translation classifications and the six status values are **separate systems**, never on one axis, ramp, legend, colour scale or numbering. `ESTABLISHED` appears in both and means different things; wherever both appear each is independently labelled |
| **Typed absence** | **`NONE IDENTIFIED` ≠ `NONE EXISTS`.** No zero, absence or unknown may be styled as failure, deficiency, negative score, rejected state, red alarm or empty progress. **`TBD` is never applied to a Triviron matter** |
| **Visual grammar ≠ populated answer** | The questions and distinctions may transfer; **Harrismith's populated answers do not**. No connector runs from a populated Harrismith object to a Triviron object |

## 9. Geometry self-check requirement

**Reference canvas `960 × 540 pt`, 16:9. Origin top left. Title zone `y = 0–72`
reserved. Side margins ≥ 48 pt — content span exactly 864 pt, `x = 48–912`.
Lowest permitted object edge `y ≤ 520`.**

**Geometry is copied from the accepted specification and never improvised.**

Every source file carries an **independent arithmetic verification** — the

**All fourteen were independently recalculated during `T7-K`, and all fourteen
reconcile.** No mathematical contradiction was found in the accepted
specification, and **no source file repairs, adjusts or reinterprets accepted
geometry.**
