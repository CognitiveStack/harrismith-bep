## 4. Treatment summary

**Ten slides rebuild as native shapes; four as native tables.**

| Approach | Slides | Why |
|---|---|---|
| **Native shapes** | 1, 2, 3, 4, 5, 7, 8, 9, 10, 11, 13, 14 | Gives full control over the solid / dashed / plain distinctions that carry governance meaning |
| **Native table** | 6, 12, and parts of 5, 9, 13, 14 | A diagram would imply a hierarchy, sequence or authority the sources do not establish |

**Native rebuild is the default, not a fallback.** The line semantics matter more
in this module than in Module 1 — a render that flattens dashed to solid asserts
an authority the sources decline to assign.

If SVG is produced later: render from committed source unchanged, name it after
its source identifier, update the register's **Rendered** column, and **preserve
the semantic line weights**.

## 5. Slide 12 — two layouts

`M02-S12` is `SOURCE PARTIAL` **by design**. The sixteen-authority register is
too dense for a one-minute slide, so the source specifies two layouts.

### 5.1 Primary simplified slide layout

Six to eight rows — **all four non-allocated authorities plus representative
allocated ones**:

| Authority | Status |
|---|---|
| Authoring · checking · coordination | `Allocated` |
| **Authorisation for controlled sharing** | **`Allocated` — clearest established** |
| Issue closure · implementation verification | `Conditional` |
| **Publication / exchange** | **`Unresolved` · `Blocked`** |
| **Acceptance for a stated purpose** | **`Unresolved` · `Recipient-dependent`** |
| **Technical / design approval** | **`Outside IM authority`** |

### 5.2 Full appendix / presenter-reference layout

All sixteen authorities with holders and statuses, as specified in
[`M02-S12`](../../assets/module-02/source/M02-S12-authority-map.md) §2.
**Appendix or presenter reference only — not a main slide.**

### 5.3 Standing instruction

> **Never remove unresolved rows from the simplified view.**

If space forces a cut, drop **allocated** rows. Ten allocated authorities are
unsurprising; three unresolved ones are the teaching. A register showing only
allocated authorities asserts a complete authority model — precisely what the
sources decline to claim.
