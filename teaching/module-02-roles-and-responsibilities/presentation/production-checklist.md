# Module 2 — Production Checklist

**Status:** To be followed while the PowerPoint is built. **Not governance.**

Work through this as the deck is assembled, not afterwards. Items marked **STOP**
are defects that must be fixed before the deck is shown to anyone.

**This checklist does not cover publication-package generation.** That programme
remains paused and is out of scope.

---

## 1. Global production checks

- [ ] **Exactly 14 slides**, numbered 1–14 in the specified order
- [ ] **16:9** aspect ratio
- [ ] Slide titles match [`deck-specification.md`](deck-specification.md) §5
      **exactly** — no paraphrasing
- [ ] Title position, size and case consistent across all fourteen
- [ ] No title wraps to three lines
- [ ] Nothing below roughly **18 pt equivalent** at 16:9
- [ ] **One principal message per slide** — if it needs an "and", it is two slides
- [ ] No more than **five supporting items** on any slide
- [ ] No paragraph-style text blocks
- [ ] Generous margins; no edge-to-edge content
- [ ] Each slide carries the primary visual named in
      [`asset-manifest.md`](asset-manifest.md)
- [ ] Presenter cues from [`presenter-cues.md`](presenter-cues.md) embedded in
      the notes pane, or supplied alongside
- [ ] Per-slide time allocation carried into the notes pane
- [ ] Block totals: 2 · 2 · 2 · 5 · 3 · 2 · 3 · 1 = **20.0 minutes**
- [ ] Nothing in the deck describes the timing as measured or rehearsed

## 6. Visual semantics

- [ ] **Solid** = supported allocation or governed progression
- [ ] **Thick / emphasised** = direction of derivation (Slide 10 only)
- [ ] **Plain line, no arrowhead** = non-hierarchical functional relationship
      (Slides 4, 5)
- [ ] **Dashed** = unresolved, blocked, future or unimplemented
- [ ] The same shape and weight means the same thing on every slide
- [ ] No gradients, shadows, icon sets, stock photography or product chrome
- [ ] No diagram styled to resemble a platform interface

## 7. Density

- [ ] **No raw responsibility matrix** on any main slide — Slide 9 shows four
      rows and three role columns
- [ ] **No full sixteen-authority register on the main Slide 12** — six to eight
      rows, with all four non-allocated authorities retained
- [ ] **No source-map extract** anywhere in the deck
- [ ] No table exceeds six rows or three columns on a main slide
- [ ] Extracts captioned as extracts

## 9. Evidence and attribution

- [ ] Footer evidence labels present where a claim is quoted, extracted or is
      synthesis
- [ ] Footers legible but unobtrusive — small, low-contrast, bottom of slide
- [ ] **No full file path** on any slide — use plain-English document names
- [ ] Slide 8's example carries the source's own label — *educational workflow
      example only*, no geometry, coordinates, Issue identifier, tolerance or
      named person
- [ ] Teaching-synthesis statements identifiable — Slides 1, 6, 12, 13, 14

## 10. Accessibility

- [ ] Text-to-background contrast sufficient for a projected room
- [ ] **Meaning never carried by colour alone** — the solid / dashed distinction
      must survive greyscale
- [ ] **Dashed versus solid readable at projection scale** — test it; a fine dash
      disappears on a projector, and that would silently complete an incomplete
      visual
- [ ] Diagram labels are real text, not baked into an image, wherever possible
- [ ] Text alternatives supplied in the notes for any placed image
- [ ] Deck legible if printed in black and white
- [ ] Full pass at presentation scale on the actual display, not a laptop preview

## 11. Final export review

- [ ] No placeholder text, no `TODO`, no lorem ipsum
- [ ] File name and title metadata do not imply an issued or published artefact
- [ ] Deck understood to be a **teaching artefact with no governance authority**
- [ ] **No rehearsal has been performed** — do not record timings as observed
