# Harrismith Fire Station — BIM Execution Plan

## Document purpose and status

**Purpose.** This document is the BIM Execution Plan (BEP) for the Harrismith
Fire Station project. It defines how information is produced, shared,
coordinated, reviewed, approved and delivered on the project.

**Status.** *Scaffold only.* This document has no baseline. It contains the
approved section architecture and placeholders. It contains no policy.

| Field | Value |
|---|---|
| Document status | Scaffold — not a baseline |
| Baseline | None. Baseline 0.1 has not been started. |
| Classification | PROPOSED GOVERNANCE (structure only) |
| Authority | None. This document carries no project authority. |
| Architecture | Architecture Baseline v1 (frozen at Gate B) |
| Issued to CDE | No |

**Scope of the current increment.** Implementation Increment 1 established the
repository scaffold only. Substantive drafting begins in a later controlled
increment with an explicitly approved scope.

**Section architecture.** The thirteen sections below are frozen as
Architecture Baseline v1. They are not to be renumbered, merged, split or
resequenced during implementation. See `README.md` section 5.

**Statement classification.** All statements in this document are to be
classified as OBSERVED FACT, TRAINING ASSUMPTION, PROPOSED GOVERNANCE,
APPROVED GOVERNANCE or UNRESOLVED DECISION. See `README.md` section 6.
