# Workshop record — template

**This is a blank template.** Copy it to a new file in `working/workshops/` for
each workshop. Do not edit this file with workshop content.

A workshop record is **working material**. It carries no governance authority. A
workshop produces proposals, options and reasoning — **it is not a decision
authority** (Working Process WP5). Where the matter has governance significance,
the decision is taken through the governance route and recorded in
`supporting/governance-decision-register.md`.

Record only what is useful. Omit fields that do not apply.

---

## Workshop / topic

*Subject of the session.*

## Related Working ID(s)

*`WP-nnn` references from `working/bep-working-register.md`.*

## Date

*Actual date only. Leave blank if not held.*

## Participating functions

*Roles and functions — not participant names.*

## Purpose

*What the session set out to resolve or explore.*

## Evidence / references

*What was examined: controlled documents, observations, records. Note the
classification of each — OBSERVED FACT, TRAINING ASSUMPTION, PROPOSED
GOVERNANCE, APPROVED GOVERNANCE, UNRESOLVED DECISION.*

## Options discussed

*Options considered, with their trade-offs. Options are not decisions.*

## Proposed outcome

*What the session proposes. A proposal is not an approval.*

## Decision required?

*Yes / No. If yes: what decision, and which function should take it. Do not name
a decision owner where none is established.*

## Actions

*Action, owning function, and status. Not participant names.*

## Related governance / Issue references

*Governance Register IDs and governed project Issue references, where they
exist. Do not create new governance IDs here.*

## Verification / follow-up

*What must be checked afterwards, and by which function. A decision made is not
a change completed.*
