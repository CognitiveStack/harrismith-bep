# BIM Delivery Guide

## Document purpose and status

**Purpose.** Practical guidance for delivery teams working on the Harrismith
Fire Station project — how to actually do the things the BIM Execution Plan
requires.

**Status.** *Scaffold only.* No guidance has been written.

| Field | Value |
|---|---|
| Document status | Scaffold — not a baseline |
| Classification | PROPOSED GOVERNANCE (structure only) |
| Authority | None — explanatory, not governing |
| Relationship to BEP | Subordinate. Explains; does not define. |

**Relationship to the BEP.** This guide explains and supports the BEP. It does
not define requirements and it does not override the BEP. Where this guide and
the BEP appear to conflict, the BEP governs and the conflict is raised as an
UNRESOLVED DECISION in `supporting/governance-decision-register.md`.
