# CDE Workflow & State Strategy

## Document purpose and status

**Purpose.** Defines how information moves through the Common Data Environment
on the Harrismith Fire Station project — the container states, the transitions
between them, and the controls that govern each transition.

**Status.** *Scaffold only.* No states, transitions or controls have been
defined.

| Field | Value |
|---|---|
| Document status | Scaffold — not a baseline |
| Classification | PROPOSED GOVERNANCE (structure only) |
| Authority | None |
| Supports | BEP section 6 — Common Data Environment Strategy |

**Population rule.** This strategy is to be populated from the observed
configuration of the project CDE and confirmed project requirements. The
observed CDE configuration is recorded as OBSERVED FACT; anything adopted for
the training implementation is recorded as TRAINING ASSUMPTION. The two are
not merged.

**Safety boundary.** Developing this document does **not** authorise any read
from or write to the Autodesk Desktop Connector / ACCDocs tree, and does not
authorise any change to the CDE configuration. See `README.md` section 2.1.
