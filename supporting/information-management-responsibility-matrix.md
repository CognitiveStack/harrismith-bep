# Information Management Responsibility Matrix

## Document purpose and status

**Purpose.** Defines who is responsible for each information-management
function on the Harrismith Fire Station project — the management-layer
responsibilities for producing, checking, approving, authorising and
maintaining project information.

**Status.** *Scaffold only.* No responsibilities have been assigned.

| Field | Value |
|---|---|
| Document status | Scaffold — not a baseline |
| Classification | PROPOSED GOVERNANCE (structure only) |
| Authority | None |
| Supports | BEP section 5 — Information Management Roles and Responsibilities |

**Population rule.** This matrix is to be populated only from confirmed project
appointments and confirmed organisational information. Roles are not to be
invented, inferred from job titles, or carried across from other projects.
Where an assignment is not confirmed, it is recorded as an UNRESOLVED DECISION
rather than filled with a plausible name.
