# Model / Information Responsibility Matrix

## Document purpose and status

**Purpose.** Defines which task team is responsible for authoring and
maintaining each model and each information container on the Harrismith Fire
Station project, and to what level of information need.

**Status.** *Scaffold only.* No models or containers have been allocated.

| Field | Value |
|---|---|
| Document status | Scaffold — not a baseline |
| Classification | PROPOSED GOVERNANCE (structure only) |
| Authority | None |
| Supports | BEP section 7 — Information Production and Sharing |

**Population rule.** This matrix is to be populated only from the observed
project model structure and confirmed task-team appointments. Model
allocations are not to be invented or assumed from discipline convention.

**Note on observed structure.** Where the live project's model and
collaboration structure differs from what the allocation would otherwise
suggest, the observed structure is recorded as an OBSERVED FACT and the
divergence is carried as an UNRESOLVED DECISION in
`governance-decision-register.md`. Observed structure is not silently
corrected in this matrix.
